# Nathan Terminal

A personal financial intelligence and trading analysis terminal combining market data, technical analysis, AI-assisted research, and candle forecasting.

## Project status

Initial repository setup.

## Planned stack

- Frontend: React, TypeScript, Vite, Tailwind CSS, TradingView Lightweight Charts
- Backend: Python, FastAPI, Pydantic, SQLAlchemy
- Forecasting: Kronos-mini
- AI analysis: configurable Gemini model
- Market data: Twelve Data, Binance public market data, and Yahoo Finance fallback

## Safety

This application is for research and decision support. It does not place broker orders or execute trades automatically. Risk checks and human review are required before any trade decision.
